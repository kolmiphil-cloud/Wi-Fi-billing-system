# 🌐 WiFi Billing System

A professional WiFi billing and hotspot management system built using PHP, MySQL, and XAMPP.  
This system allows administrators to manage users, generate vouchers, monitor balances, and view system statistics through a modern dark-mode admin dashboard.

---

# 🚀 Features

## 👨‍💼 Admin Features
- 📊 Dashboard with system statistics and charts
- 👥 User management
- 🎟️ Voucher generation
- 💳 User balance tracking
- 🌙 Dark mode admin panel
- 📱 Mobile responsive sidebar navigation

## 👤 User Features
- 🔐 User registration
- 🔑 Secure login system
- 💰 Balance tracking

## 🎨 UI Features
- Modern admin panel layout
- Sidebar navigation
- Dark theme interface
- Responsive design (mobile + desktop)
- Chart.js integration for statistics
